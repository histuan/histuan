## Main project

### [Multi-Account Launcher for Claude](https://github.com/histuan/Claude-Launcher)

[![Latest release](https://img.shields.io/github/v/release/histuan/Claude-Launcher?label=latest%20release&color=d97757)](https://github.com/histuan/Claude-Launcher/releases/latest) [![CI](https://github.com/histuan/Claude-Launcher/actions/workflows/claude-launcher.yml/badge.svg)](https://github.com/histuan/Claude-Launcher/actions/workflows/claude-launcher.yml) [![License: MIT](https://img.shields.io/github/license/histuan/Claude-Launcher?color=d97757)](https://github.com/histuan/Claude-Launcher/blob/main/LICENSE)

A Windows launcher that keeps several Claude accounts signed in at the same time, each one in its own isolated instance of the official Claude desktop app. Pick an account, click, done.

- Add accounts with e-mail or Google sign-in, open them side by side, and see which ones are running.
- Move memories from one account to another with a guided assistant.
- Updates itself from GitHub Releases; every release is built and published by CI.
- Built with TypeScript and Electron, with 220 automated tests.
